# 조건별 전체 대화로그

원자료(jsonl)에서 그대로 옮겼다. 손님 대사·시나리오는 `draft_pending_user_approval` 상태다.

| 조건 | 설명 | 대화 수 | 턴 수 | 결정 정답 일치 |
|---|---|---:|---:|---:|
| [M0P0](M0P0.md) | 기준선. 과거 대화를 벡터 검색(RAG)해 넣고, 결정과 대사를 모델이 함 | 81 | 648 | 266/648 |
| [M0P0R](M0P0R.md) | M0P0 + 결정표를 프롬프트로 알려줌(결정은 모델) | 54 | 432 | 188/432 |
| [M1P0](M1P0.md) | 구조화 기억(출처 표시). 결정과 대사를 모델이 함 | 81 | 648 | 258/648 |
| [M1P0R](M1P0R.md) | M1P0 + 결정표를 프롬프트로 알려줌(결정은 모델) | 54 | 432 | 189/432 |
| [M1P1](M1P1.md) | 구조화 기억 + 코드 승격 정책. 대사는 모델 | 81 | 648 | 501/648 |
| [M1P2](M1P2.md) | M1P1 + 결정 근거 문구·말투 예시 주입 | 54 | 432 | 329/432 |
| [M1P2G](M1P2G.md) | M1P1 + 실제 엔진 상태(출처 표시) 주입 | 54 | 432 | 329/432 |
| [M1P3](M1P3.md) | M1P2G + 최종 대사를 엔진 템플릿으로 조립(모델 원문은 감사 기록) | 54 | 432 | 329/432 |
| [M1P4](M1P4.md) | M1P1 + fail-closed 정책(술어를 못 읽은 주장은 고위험) | 81 | 648 | 504/648 |
| [M1P5](M1P5.md) | M1P1 + 개선 NLU 지시문(V2) | 81 | 648 | 407/648 |

- M0P0·M1P0·M1P1은 본실험 18편과 적대적 실험 9편(S20~S22)을 함께 담았다.
- '결정 정답 일치'는 로그의 모든 턴을 그대로 센 값이다. 논문 지표(예: M1P1 결정 일치율 0.8265 = 181/219)는 채점 대상 턴만 세므로 값이 다르다. 공식 수치는 `results/metrics.csv`를 본다.
- M1P4·M1P5는 27편(본실험 18 + 적대적 9) × 3 seed다.
