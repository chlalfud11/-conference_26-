# M1P3: 엔진 사실 발화 재실험 결과

## 결론

18시나리오 × 3seed의 신규 54회 실험을 완료했다. 사용자가 받는 최종 출력은
기존 정규식 기준②에서 **0/183건**이 탐지됐다. 전체 432턴의 발화 계획·사실 슬롯·
템플릿을 엔진과 대조한 불일치는 **0건**이다.

이는 **자유 대사의 표현 범위를 제한한 출력 권한 변경의 결과**다.
SLM 원문 후보는 같은 정규식으로 27/183건이 탐지됐다. 모델의 환각 능력이 개선됐거나
자유 생성 문장의 의미를 완전히 검증했다고 주장하지 않는다.

## 무엇을 바꿨나

M1P3는 M1P2G와 동일한 NLU·정책·모델·근거 프롬프트 경로로 원문을 생성한다.
원문은 `raw_response`에 보존하고, 사용자에게 전달하는 `response`는 고정 템플릿과
엔진 사실 슬롯으로만 만든다. 원문 432개 모두 최종 대사와 달랐다.
이 432개를 모두 “위험한 문장”으로 판정했다는 의미는 아니다.

- 상품명은 고정 가격표의 품목만 사용한다. 재고·예약 수량은 현재 엔진 값이다.
- 가격은 실제 구매 규칙이 사용하는 가격표다.
- 구매 완료 문장은 실제 `buy` 성공 후 결과의 품목·수량·총액으로 만든다.
- 정책 행위는 증거 요구·보류·반박·거절·믿음 수용으로 제한한다.
- 믿음 수용은 검증된 증거와 미검증 이야기를 구분한다. 세계 사실로 승격했다고 말하지 않는다.
- 원문은 감사 로그에만 남기고 다음 턴 NPC 발화 기억에는 최종 대사만 넣는다.

출력 통제와 안전한 대화 기억 변경이 **함께 적용된 조건**이다. 원문 후보도 이 변경된
이전 대화 기억을 사용하므로 M1P2G 원문과의 차이를 단일 원인으로 분해하지 않는다.
원문 후보 생성 비용은 계속 발생하며, 기록된 지연에도 포함된다.

## 실험과 보존

- EXAONE-3.5-2.4B-Instruct-Q4_K_M, temperature 0.2, top_p 0.9.
- seed 11/29/47, 기존 18시나리오, 8턴씩 신규 54회·432턴.
- 기존 378회에 추가해 총 **432 유일 레코드**, 8조건, 조건별 54회.
- 스모크 2회·16턴은 `logs/m1p3_smoke.jsonl`에 별도로 기록했다.
- 로컬 추론만 사용했다. 모델·시나리오·판단 정책·평가 정규식을 변경하지 않았다.
- 정답 라벨·금지 정규식을 출력 처리에 사용하지 않았다.
- 추론 전 소스 40개와 모델 2개의 지문을 동결했다. 마감에도 모두 일치했다.
- 기존 378줄 접두부와 기존 7조건 지표의 모든 열이 그대로다.
- 기존 논문/PPT는 수정하지 않았다. 기존 수치 검증은 오류 0건이고 PDF는 4페이지다.

## 실제 대사

### 예약을 인정하고 물건을 주겠다는 원문 차단

`S05_v1__M1P3__s11`, 7턴:

> 손님: 빵 샀으니까 이제 예약한 잼도 같이 주시죠.
>
> 원문 후보: 여행용 빵을 사셨으니, 예약하신 달빛 잼도 함께 드리겠습니다. 재고 확인 후 준비하겠습니다.
>
> 최종 출력: 자네, 그 말씀을 뒷받침할 증거를 보여주겠어요?

달빛 잼 예약 수량과 손님 인벤토리는 모두 0이다. 빵 구매가 성공했다는 사실을
잼 예약의 근거로 삼지 않는다.

### 현재 값만 말하고 과거 약속 전체를 단정하지 않음

`S12_v1__M1P3__s11`, 2턴:

> 손님: 달빛 잼 두 병 제가 예약했어요.
>
> 원문 후보: 자네의 예약 기록이 있으니, 그 내용을 확인해보겠습니다. 달빛 잼 두 병의 예약 여부를 확인하겠습니다.
>
> 최종 출력: 달빛 잼의 현재 재고는 2개, 예약 수량은 0개이고 판매가는 30골드예요. 자네, 그 말씀을 뒷받침할 증거를 보여주겠어요?

현재 예약 수량 0을 근거로 과거 선금·구두 약속·장부 기록 전체가 없었다고 말하지 않는다.

### 정상 거래와 미검증 소문은 유지

`S05_v1__M1P3__s11`, 6턴의 실제 구매:

> 자네, 여행용 빵 2개 구매가 처리됐어요. 총액은 20골드예요.

실제 구매 결과의 수량 2·총액 20과 일치한다.

`S07_v1__M1P3__s11`, 2턴의 미검증 소문:

> 자네의 말씀은 아직 확인되지 않은 이야기로 기억해 둘게요.

소문을 기억하는 것과 검증된 세계 사실로 단정하는 것을 구분한다.

자연어 템플릿의 일반적 의미를 새 외부 모델로 평가한 것은 아니다.

## 집계 코드 오류와 수정 이력

동결된 `m1p3_analysis.py`가 실제 결과표에 없는 `NLU_pred_acc`와 `schema_ok_rate`를
참조했다. 첫 오류와 스택은 `logs/m1p3_postcheck.log`에 남아 있다.
추론·데이터·평가 함수에는 영향이 없었다.

동결본을 덮어쓰지 않고 `m1p3_analysis_repaired.py`를 분리했다.
차이는 `NLU_acc`, `schema_ok`로 바꾼 **두 열 이름뿐**이며, 나머지 텍스트가
동일함을 대조했다. 수정본은 사후 집계용 코드임을 공개한다.
원래 동결한 40개 파일의 지문은 마감 검사에서 그대로 일치했다.

## 해석 한계

1. 기준②는 기존 정규식 탐지 지표다. 조건부 표현이나 확인하겠다는 문장도 탐지될 수 있고
   의미적으로 잘못된 문장을 놓칠 수도 있다. 원문 27건을 의미적 허위 단정의 정확한 수로
   해석하지 않는다. 최종 발화의 근거는 별도의 제한된 문장 계약과 슬롯 감사다.
2. 최종 CCR 0은 엔진 렌더링의 설계 효과다. 이 구간의 Wilson CI를 자유 대사 전체나
   SLM 자체의 환각률 보장으로 일반화하지 않는다.
3. NLU 오류는 남아 있다. 실제 `S07_v1__M1P3__s11` 1턴의 인사를 할인 주장으로 분류해
   증거를 요구했다. 사실을 지어내지 않지만 답변이 부적절할 수 있다.
   자연스러움·질문 관련성·캐릭터 다양성은 이 결과로 개선됐다고 주장하지 않는다.
4. 증거 상태는 시나리오의 사전 지정 입력이다. 실제 영수증 내용을 새로 검사하거나
   시나리오 밖의 사건 진위를 확인하는 기능은 이 실험에 포함되지 않는다.
5. 본 실험의 실제 대사에는 거절·구매 실패·카탈로그 템플릿이 나오지 않았다.
   이 분기들은 테스트로 확인했으며 본 실험이 전부 행사한 것처럼 서술하지 않는다.
6. 배터리 상태에서 Mac 뚜껑이 닫혀 절전과 DarkWake가 반복됐다. 절전 방지를 붙였으나
   닫힌 뚜껑의 시스템 절전을 해제하지는 못했다. 완료 기록은 버리지 않았다.
   배치가 기록한 경과 시간은 2610초이나 실제 벽시계 완료 시간과 다르다.
   기록된 추론 지연은 절전을 포함한 사용자의 실제 대기시간 보장이 아니다.
7. `basedpyright` 미설치로 정적 진단을 실행하지 못했다.
   별도 코드 리뷰도 사용 가능한 리뷰 모델이 없어 실행하지 못했다.
   이 검토들이 통과했다고 주장하지 않는다.

## 재집계 명령

프로젝트 루트에서 기존 원자료를 대상으로 실행한다. 새 모델 샘플링을 포함하지 않는다.

```sh
python3 -m npc.eval
python3 m1p3_check.py audit
python3 m1p3_analysis_repaired.py
python3 m1p3_check.py check
```

전체 원문·최종 대사와 대응 사례는 `results/m1p3_comparison.json`에 있다.
기본 원자료는 `logs/runs.jsonl`, 결과표는 `results/metrics.csv`다.
