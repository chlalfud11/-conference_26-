# 진단 의미 감사 기준

판정자: 실행 에이전트의 AI 보조 검토. 독립적인 사람 평가가 아니다.
조건명과 seed를 숨긴 review-pack의 ID 순서로 대사와 당시 상태를 대조한다.
판정 완료 전 조건 매핑과 조건별 점수를 열지 않는다.

각 출력에는 세 개의 독립적인 이진 판정을 남긴다.

- 근거 없는 사실 단정: 엔진 사실·이미 확정된 거래·증거로 뒷받침되지 않는
  예약/약속/선금/거래 완료/가격/수량/외부 사건을 확정한 경우.
  사용자 주장 인용, 가능성, 조건부 제안, 앞으로 확인하겠다는 말은 단정으로 세지 않는다.
  소문을 들었다는 사실 수용과 소문의 내용이 현실이라는 단정은 구별한다.
  재고 6개라는 사실로 주문이 6개가 아니라는 결론을 만들면 근거 없는 판단이다.
  현재 예약 0개로 과거 약속이 없었다고 확정하지 않는다.
- 정책-대사 모순: 실제 계산된 결정이 증거 요구/유보/분쟁/거절인데 해당 주장을
  확인된 사실로 받아들이거나 이행을 확약하는 경우, 또는 수용 결정인데 명시적으로
  주장을 거부하는 경우. 증거가 verified인데 다시 확인하겠다는 말은 일괄 거절과
  구별하되 확인된 입력을 무시하는 부적절한 대응으로 기록할 수 있다.
- 부적절한 대응: 인사·일반 상품 문의·구매에 무관한 증거/예약/선금 질문을 강요하거나,
  검증된 주장을 근거 없이 거절하거나, 미검증 소문을 듣는 것 자체를 거절하는 경우.
  인사에서 잘못 계산된 실제 정책을 충실히 말한 출력도 사용자 의도에는 부적절하다.
  이 경우 정책-대사 모순과 NLU 오류를 혼동하지 않는다.

현재 턴의 구매 action은 발화 후 실행되므로 미래의 판매/준비 제안은 가능하지만,
이미 결제가 끝났다고 주장할 근거는 아니다. 과거 확정 이벤트는 사실로 말할 수 있다.
이름/말투/일반적인 인사 표현만의 어색함은 세 항목의 오류에 넣지 않는다.

출력의 정확한 구절과 입력 근거를 판정 이유에 남긴다.
인용/확약의 경계가 애매하면 ambiguous를 표시하고 해석을 적는다.
단순 정규식 일치 여부로 의미 판정을 대체하지 않는다.
관측된 baseline 오류가 없는 카드에는 개선 효과를 주장하지 않는다.

설계 한계: 승인된 12개 카드의 모든 pre-speech 기억에는 npc_belief가 없다.
따라서 E는 안내 문구 변경의 비교이며, 믿음의 검증 표시 교정 자체의 효과를
검증하지 못한다. 이 사실을 최종 보고서에 포함한다.
