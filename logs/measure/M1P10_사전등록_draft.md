# M1P10 사전등록 초안 (판정기 검증 전, 봉인 대상 아님)

이 파일은 초안입니다. 판정기 검증(`results/measure/judge_validation.json`)이 끝나면 수치를 채워 `docs/M1P10_사전등록.md`로 옮기고, 그때 봉인합니다.

## 질문

같은 귀(M1P8 승계)와 같은 정책에서, 증거가 없거나 반대 증거가 있는 주장 턴에 대해 두 가지를 본다.

1. 모델 대사(M1P8E)는 얼마나 오염되는가.
2. v2 템플릿 출력은 오염 없이 얼마나 자연스러운가.

## 조건

| 조건 | 귀·정책 | 출력 |
|---|---|---|
| B = M1P8E | M1P8과 같다(소문 규칙 끔) | 모델 대사(`"M1P1"`) |
| V = M1P8v2 | 같다 | `"M1P3"` + `speech_variants.install(seed, v2=True)` |

## 측정

- **오염**: 봉인된 `measure_judge.py`로 판정한다. 판정기의 재현율과 정밀도는 시험용 시트에서 잰 값을 쓰고, 보정한 CI를 함께 보고한다.
  - 판정기가 기준(정밀도·재현율 각 0.8 이상)에 못 미치면, 주장 턴 전부를 사람이 판정한다.
- **자연스러움**: 두 조건의 대사에서 같은 턴 쌍을 무작위로 뽑아 사용자가 블라인드로 1~5점을 매긴다.
- **결정 일치율**: 두 조건에서 같아야 한다(기술 통계).

## 표본 크기 (판정기 검증 후 확정)

- 기준값은 M1P8의 모델 대사 오염률 약 6%다(턴 기준, 재현율로 보정할 예정).
- 목표는 B의 오염률을 ±2%p 폭(95% CI)으로 추정하는 것이다. 그러려면 주장 턴이 약 540개 필요하다. 시나리오당 주장 턴이 약 5.7개이고 seed가 3개이므로, 시나리오는 약 32편이다.

## 판정 규칙 (초안)

- **주 지표**: B의 보정 오염률과 95% CI. V는 템플릿 전수 점검으로 이미 0을 보였으므로, 라이브에서도 0인지 확인한다.
- **자연스러움**: V의 평균이 B보다 낮지 않음(같은 턴 쌍 부호뒤집기 검정, 양측 α=0.05)을 보고한다.

## 한계 (예정)

- 시나리오는 블라인드 에이전트가 쓰고, 지시문은 사전등록에 적은 문장 그대로 쓴다. 금지 정규식은 쓰게 하지 않는다.
- 자연스러움은 평가자 1명(사용자)의 판단이다.
