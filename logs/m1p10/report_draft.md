# 라이브 M1P10 결과 (모델 대사 vs v2 템플릿, 턴별 이중 판정)

작성: 2026-10-17. 사전등록은 `docs/M1P10_사전등록.md`이고, 계획은 `.omo/plans/m1p10-measurement-root-cause.md`이다.

## 이 실험까지 오게 된 과정 (근본 원인 → 해결)

1. **근본 원인**: M1P6~M1P9는 대사 오염을 재는 자(정규식)를 실험마다 새로 만들었고, 그 자를 한 번도 검증하지 않았다. 그래서 M1P8에서는 오탐이, M1P9에서는 미탐이 났다.
2. **자 검증**: 일반 확정 표현 사전으로 만든 판정기를 개발용 시트에서 봉인했다. 시험용 시트에서는 가중 정밀도 0.50, 재현율 0.34가 나와 기준(각 0.8)에 못 미쳤다. 표현 목록 방식은 새 대사에 일반화되지 않는다는 것이 확인됐다.
3. **판정 방법 교체**: 턴마다 두 언어모델(Claude Opus, GPT)이 각자 판정하고, 서로 다른 줄만 조정자가 정한다. 측정 도구 단계에서 두 모델의 일치도는 카파 0.89(개발용), 0.81(시험용)이었다.
4. **출력 개선**: 모델 교체 비교에서 가장 나은 EXAONE 7.8B도 자연스러움이 2.38점(5점 만점)에 그쳤다. 대사가 어색한 진짜 원인은 대답 종류를 고르는 규칙이었으므로 v2 템플릿으로 이를 고쳤다.
   - 기존 템플릿 → 새 말투: 1.12점 → 1.47점(p=0.008).
   - v2: 사용자의 비공식 판단은 "훨씬 자연스럽다"였다.
   - v2 템플릿은 정책 문장이 붙는 조합까지 펼친 226개 전부를 점검했고 오염 문장은 0개였다.

## 한계

1. 오염 판정은 사람이 아닌 두 언어모델과 조정자가 했다. 사람 1명과 모델 판정의 일치도는 카파 0.54(60줄)로 낮았다.
2. 정답 라벨에 대해 사용자 1명이 30줄 중 25줄을 "틀림"으로 판정했다. 정답 라벨 체계의 타당성은 아직 해결되지 않았다.
3. 판정 대상 턴은 조건마다 약 290개로, 사전등록에서 근거로 든 540개보다 적다. 그만큼 신뢰구간이 넓다.
4. 조정자는 템플릿 문장을 알아볼 수 있다. 판정 시트에서 조건 이름은 가렸지만, 어느 쪽 대사인지 짐작할 수 있다.
5. v2의 자연스러움은 이번 실험에서 측정하지 않았다.
