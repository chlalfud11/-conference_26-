# M1P3: 사실 발화 권한을 엔진으로 제한하는 재실험

## 요청과 변경 범위

사용자 요청: “허위 단정 해결해서 다시 실험해줘”.
정확한 근거를 프롬프트에 넣어도 SLM이 예약과 할인 사실을 지어내는 사례가 남았다.
새 조건 M1P3는 최종 발화를 만드는 권한을 변경한다.
기존 M1P2G와 같은 NLU·정책·모델·근거 프롬프트로 원문 후보를 생성하지만,
후보 문장을 그대로 출력하지 않는다.

사용자가 받는 문장은 사전 고정된 대화 행위와 엔진 사실 슬롯으로 렌더링한다.
자유 대사의 표현 범위가 좁아지는 대가를 공개한다.
최종 발화의 안전성을 SLM 자체의 환각 능력이 개선됐다는 성과로 제시하지 않는다.

## 보존 기준

기존 7조건 378회 원자료 전체 SHA256:

`a6249e2b02f75e712b8541fdc74fc8d8649b6d900ae8037cee7f7688fb8c0369`

기존 레코드, 프롬프트, 시나리오, 판단 함수와 평가 정의를 변경하지 않는다.
정답 라벨과 금지 정규식은 출력 문장 생성이나 차단에 사용하지 않는다.
기존 7행 지표를 신규 추론 전 보존한다.

## 출력 계약

1. 모델 원문 후보는 `raw_response`로 보존한다. 무슨 문제가 있었는지 숨기지 않는다.
2. 최종 `response`는 엔진이 만든 발화 계획과 고정 템플릿으로만 생성한다.
   임의 모델 문장과 미검증 사용자 문자열을 사실 문장의 슬롯에 넣지 않는다.
3. 상품명은 고정 가격표의 품목만 사용한다. 현재 재고·예약 수량은 실제 엔진 값이다.
   예약 수량 0을 근거로 과거 약속이나 선금 기록 전체가 없었다고 단정하지 않는다.
4. 구매 완료 문장은 실제 `buy` 성공 결과로만 만든다. 구매 실패는 실제 실패 이유로
   응답하며, 다른 물건을 주겠다는 약속을 추가하지 않는다.
5. 믿음 수용은 검증된 증거와 미검증 이야기를 구분한다. 믿음이 생겼다고 세계 사실이나
   거래가 확정됐다고 말하지 않는다. 증거 상태는 시나리오 입력이며 실제 영수증 검사를
   새로 수행했다는 의미가 아니다.
6. 인사·작별·상품 문의·증거 요구·보류·반박·거절도 고정된 대화 행위로 처리한다.
7. 원문 후보는 감사 로그에만 남기고, 다음 턴 대화 기억에는 최종 발화만 넣는다.
   출력 통제와 안전한 대화 기억 변경이 함께 적용된 조건임을 공개한다.

정규식이 후보의 의미를 완전히 판정할 수 있다고 가정하지 않는다.
모델 문장을 부분적으로 고치는 대신, 사실을 말할 수 있는 문장 집합 자체를 제한한다.
발화 계획과 렌더링 템플릿의 최종 문구는 최초 신규 추론 전에 동결한다.

## 검증 기준과 증거

### H1: 원문 누출과 후속 기억 오염 방지

관측된 허위 예약·할인 후보와 기계용 누출 sentinel을 모의 모델 응답에 넣는
통합 테스트로 원문은 정확히 감사 로그에 남고 최종 출력과 다음 턴의 NPC 발화 기억에는
들어가지 않음을 확인한다. 실제 CLI에서도 원문과 최종 대사를 모두 확인한다.
사용자 입력 자체에 들어 있던 주장과 NPC가 생성한 원문은 구분한다.

### H2: 정상 동작과 사실 슬롯

예약 0/양수, 정상/실패 구매, 재고·가격 문의, 증거 요구·보류·반박·거절,
검증/미검증 믿음 수용, 인사·작별을 관련 테스트와 실제 출력에서 확인한다.
사실 슬롯은 엔진 값·실제 거래 결과·가격표에 일치해야 한다.
최종 문장은 동결된 템플릿으로만 생성돼야 한다.
자연어 문구를 점수에 맞추거나 테스트로 고정하지 않는다.

### H3: 기존 조건 불변

S05_v1 seed11의 원본 NLU·대사를 고정하고 실제 로컬 임베딩을 사용해
기존 7조건의 저장된 프롬프트 해시 56개가 모두 일치하는지 확인한다.
이는 새 샘플링이 항상 같은 전사를 낸다는 주장이 아니다.

### H4: 최종 발화 계약의 전체 대조

본 실험 432턴의 발화 계획을 같은 초기 상태·거래·정책 입력으로 재구성한다.
템플릿 식별자, 슬롯과 출처를 독립 대조하고 최종 출력의 템플릿 일치를 확인한다.
원문과 최종 출력의 기준②/CCR, 결정 지표, 지연과 대사를 분리해서 보고한다.
기존 정규식 오탐·미탐은 평가 기준을 수정하지 않고 한계로 기록한다.

### H5: 추론 전 동결과 마감 보존

런타임·템플릿·테스트·시나리오·평가·계획·감사 코드와 모델의 전체 지문을 신규 추론 전에
저장한다. 원본 378줄 접두부와 기존 7조건 지표 모든 열이 마감에도 같아야 한다.
보고 수치는 원자료를 따라야 한다. 기존 논문 수치 오류 0건과 4페이지를 유지한다.
미설치 정적 진단이나 실행되지 않은 독립 검토를 통과했다고 주장하지 않는다.

### H6: 보고서와 자원 정리

관측된 원문 문제와 최종 출력, 표현 자유도 제한, 안전한 기억 변경의 결합 효과를
보고서에 공개한다. 서버·포트·소유 임시 파일을 정리하고 영수증을 기록한다.

H1~H6과 별도 보고서가 완성되면 결과를 과장하지 않고 전달한 뒤 종료한다.
