# NLU V8 실험 사전등록 (하이브리드 귀: 언어모델 + 임베딩 kNN, 사람이 쓴 평가 세트)

작성: 2026-10-16. 이 문서와 `nlu_hybrid.py`는 평가 세트 6이 만들어지기 **전에** 봉인한다(`logs/nlu_hybrid/prompt_freeze.json`). 학습용 세트 2~5의 해시도 함께 봉인한다.

## 1. 배경

- 같은 언어모델로 만든 귀(B, V5, V6, V7)끼리는 오류가 겹쳐 조합해도 나아지지 않았다. 세트3~5 기록으로 오프라인 확인한 결과다.
- 결과를 본 뒤의 파일럿(post hoc)에서, bge-m3 임베딩 kNN(k=7, 세트2~5로 학습)은 원래 시나리오 대사 144줄에서 .840을 기록했다. 같은 턴에서 B는 .755였다. 두 귀의 오류는 일부만 겹쳤다(둘 다 틀림 35, B만 71, kNN만 34). 파일럿 수치는 결과를 보고 고른 것이므로 확정 근거가 아니다.

## 2. 가설

언어모델 귀 B와 임베딩 귀 kNN이 **둘 다 고위험이라고 할 때만** 고위험으로 판정하면(V8_AND), 처음 보는 사람이 쓴 문장에서 위험도 정확도가 B보다 높다.

## 3. 조건

- **B**: 원본 NLU 지시문, 지금 말만 본다. seed 11/29/47로 각 1회씩 호출한다.
- **KNN**: bge-m3(FP16) 임베딩을 L2 정규화한 뒤, 코사인 유사도로 학습 문장 중 가장 가까운 7개를 고른다. 그중 고위험 비율이 0.5 이상이면 고위험이다. 학습 데이터는 세트2~5 전 문장(800줄)이고 지금 말만 본다. 결정적 방법이라 seed와 무관하다.
- **V8_AND**: B와 KNN이 둘 다 고위험일 때만 고위험이다.
- **V8_OR**: 둘 중 하나라도 고위험이면 고위험이다(안전 우선 변형).
- 새 모델 호출은 B뿐이다. 조합 조건은 같은 호출 결과로 계산한다.

## 4. 평가 세트 6 (사람 작성)

- 연구자가 대화형으로 직접 손님 대사를 쓴다. 조수는 대화마다 유형 순서와 상황(주장 종류)만 제시하고, 문장은 고치지 않는다.
- 구성: 30 대화 × 4줄 = 120줄. 유형 목표는 claim 30, insist 26, rumor_after_claim 20, none 27, rumor 17이다. 주장 종류 6가지는 각각 5대화씩 배정한다.
- 라벨은 조수가 제시한 상황을 따른다. 작성자가 의도를 바꾼 줄은 작성자에게 확인해 라벨을 정한다.
- 봉인 전에는 구성만 점검한다. 모든 문장이 서로 달라야 한다.

## 5. 지표와 검정

- 단위: 줄 × seed(3)마다 위험도(고/저) 일치 여부.
- **주 검정**: V8_AND vs B. 대화 30개 단위 부호뒤집기 순열검정(양측, α=0.05)을 `nlu_confirm.sign_flip` 규칙으로 하고, 부트스트랩 CI는 10,000회로 구한다.
- **부 검정 2개(Holm)**: KNN vs B, V8_OR vs B.
- 기술 통계: 고→저, 저→고, 유형별 정확도, B·KNN 불일치 비율, 두 귀가 일치한 줄만의 정확도(되묻기 설계의 근거).

## 6. 판정 규칙

**V8 권장**: 주 검정 p<0.05, 차이>0, V8_AND의 고→저 건수 ≤ B의 고→저 건수를 모두 만족할 때.

## 7. 종료 규칙

정해진 계산(B 120줄 × 3 seed 호출 + KNN 120줄)을 1회만 실행한다. 중단되면 빠진 부분만 이어서 실행한다. 결과를 보고 k, 임계값, 학습 데이터, 조합 규칙을 바꾸지 않는다. null 결과도 보고한다.

## 8. 미리 밝히는 한계

1. 작성자(연구자)는 블라인드가 아니다. 이전 결과와 프롬프트를 봤다. 대신 언어모델 에이전트의 문체와 독립적인 사람의 문장이라는 장점이 있다.
2. 학습 데이터(세트2~5)는 언어모델 에이전트가 썼고, 라벨은 독립 검수를 받지 않았다.
3. V8 아이디어와 k=7, 임계값 0.5는 결과를 본 뒤의 파일럿에서 나왔다.
4. 줄 단위 평가이고 문맥과 장부 승계는 쓰지 않는다. 대사와 라이브 대화는 측정하지 않는다.
5. 30 대화라 검정력이 이전 세트(50 대화)보다 낮다.
