## 6. 분석 (`nlu_m1p8_live.py analyze`)

- **주 검정**: 결정 일치율 B vs A. 시나리오 단위 부호뒤집기 순열검정(양측, α=0.05)을 `nlu_improve.sign_flip`으로 하고, 부트스트랩 CI는 10,000회로 구한다.
- **부 검정(Holm, 3개)**: 기준① B vs A, 기준② C vs B, TCAR B vs A(Fisher).
- 기술 통계: 후속 발화 정답률, 고→저·저→고, 승계 횟수와 정답률, BPA(고위험 주장을 수용했을 때 술어가 맞은 비율), 턴 지연 중앙값과 p95, 3조건 결정 일치율.

## 7. 판정 규칙

- **귀 수정 채택**: 주 검정 p<0.05, 차이>0, B의 기준① ≤ A의 기준①.
- **템플릿 결합 채택**: 기준② C vs B의 Holm p<0.05이고 C가 더 낮으며, C의 결정 일치율 ≥ B의 결정 일치율.
