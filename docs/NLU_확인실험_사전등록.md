# NLU 확인 실험 사전등록 (V1 vs B, V4 부 검정)

작성: 2026-10-15. 이 문서와 `nlu_confirm.py`는 새 문장 세트 2가 만들어지기 **전에** 봉인한다(`logs/nlu_confirm/prompt_freeze.json`).

## 1. 배경

- V1(출처 정의, 문맥 없음)은 M1P5 test에서 결정 일치 .902(원본 .850), V3 새 세트에서 위험도 정확도 .864(원본 .822)로 두 번 모두 1위였다. 하지만 두 번 모두 주 검정 대상이 아니었다.
- 문맥을 지시문으로 제한한 V3는 실패했다. 거래 주장 뒤 소문을 맞힌 경우가 7/45였다(`results/bottleneck/v3_report.md`).
- '주장 없음' 오분류: 잘못 읽힌 줄의 화행은 대부분 request·question·greeting이었다. 그러나 "화행이 주장이 아니면 술어=없음" 코드 규칙은 실제 주장과 되풀이도 지워서 손해가 더 컸다(새 세트 B 296→268, 기존 결정 일치 B 301→201). 그래서 개입에서 뺀다(`results/bottleneck/none_and_gate_design.json`).

## 2. 조건

- **B**: 원본 지시문, 지금 말만 본다.
- **V1**: 출처 정의와 일반 예시 11개, 지금 말만 본다(봉인된 `nlu_improve.py`).
- **V4**: 코드가 지금 말에서 지시어나 되풀이 표현(`nlu_confirm.MARKERS`: 그거·아까·저번에·말씀드렸·잖아요·기억 안·분명히·라니까 등)을 찾으면 V2 형식(V1 + 직전 손님 말 2개)으로, 못 찾으면 V1 형식으로 보낸다. 즉 문맥을 지시문이 아니라 **코드가 결정한다**.
- 정규식은 언어적 원리로 먼저 쓴 뒤, 이미 본 자료에서 켜지는 비율만 점검했고 그 뒤 고치지 않았다. 점검 결과는 다음과 같다. V3 세트에서 insist 22/30, claim 6/31, rumor_after_claim 0/15, rumor 0/18, none 0/26. 기존 27편에서 고위험 36/96, 소문 0/22.
- 모델, seed(11, 29, 47), 스키마, 정책은 같다.

## 3. 새 문장 세트 2

- 작성자는 이전 세트, 프롬프트, 결과, 시나리오를 보지 않은 별도 작성 에이전트다. 정의와 구성 규칙만 받는다.
- 크기: 대화 50개 × 손님 발화 4줄 = 200줄. V3 세트(30 대화)보다 검정력을 높이려고 늘렸다.
- 상태는 `draft_pending_user_approval`이다. 작성 후에는 구성만 점검하고 문장과 라벨은 고치지 않은 채 봉인한다.

## 4. 지표와 검정

- 단위: 줄 × seed 호출 1회의 위험도(고/저) 일치 여부.
- **주 검정**: V1과 B의 위험도 정확도 차이. 대화 50개를 단위로 한 부호뒤집기 순열검정(양측, α=0.05)을 쓴다. 0이 아닌 차이가 20개 이하이면 정확 계산, 그보다 많으면 100,000회 표본(seed 20261015)이다. 부트스트랩 95% CI는 10,000회로 구한다.
- **부 검정 2개(Holm)**: V4 vs V1, V4 vs B.
- 기술 통계: 술어 정확도, 고→저, 저→고, 유형별 정확도, V4 게이트 작동 수.

## 5. 판정 규칙

- **V1 권장**: 주 검정 p<0.05, 차이>0, V1의 고→저 건수 ≤ B의 고→저 건수를 모두 만족할 때.
- **V4를 V1보다 권장**: V4 vs V1의 Holm p<0.05이고 차이>0일 때.

## 6. 종료 규칙

정해진 호출(200줄 × 3 seed × 3조건 = 1,800회)을 1회만 실행한다. 결과를 보고 문장, 라벨, 정규식, 프롬프트, seed를 바꾸거나 추가하지 않는다. null 결과도 모두 보고한다.

## 7. 미리 밝히는 한계

1. 작성자는 언어 모델 에이전트이고 라벨은 독립 검수를 받지 않았다.
2. 정규식은 이미 본 세트에서 켜지는 비율을 점검했다(수정은 없음).
3. 줄 단위 NLU 평가다. 정책은 위험도에 따라 결정적으로 움직이지만, 대사는 측정하지 않는다.
4. V1을 주 검정으로 고른 이유는 앞선 두 번의 기술 결과다. 이번이 그 관찰을 확인하는 첫 사전등록 검정이다.
