# ABCD 검증 세트 추가 실행: SLM 직접 판단(F-M1P0) 사전등록

작성: 2026-10-21. 사용자 요청: "검증 세트에서 SLM 직접 판단 조건을 실험하고 보고서에 추가."
`python3 abcd5_p0.py seal`로 봉인한다. 봉인 파일 `results/abcd5p0/prereg_seal.json`에는 이 문서와 v5 봉인 파일의 해시가 들어간다. 봉인한 뒤에 실행한다.

## 목적
v4에서는 결정표(F-M1P1)가 SLM 직접 판단(F-M1P0)보다 정확도가 37.7%p 높았다. 이 차이가 처음 보는 원천(v5 검증 세트, 59원천)에서도 나타나는지 확인한다.

## 실행
- **조건**: F-M1P0. 코드 경로는 v4와 같다(`abcd4_runner.run_dialogue4`, view "full"). 손님 장부 전체를 주고, SLM이 직접 결정한다.
- **데이터와 seed**: 검증 세트 177개 시나리오 × seed 11/29/47 = 531회. `ABCD4_SET=heldout`으로 실행한다.
- **비교 대상**: 봉인된 검증 세트의 F-M1P1(531회)과 T-M1P0(531회) 기록.

## 지표
분석 단위와 검정은 v4·v5·v6과 같다. 원천 단위로 짝지은 sign-flip을 20,000회 하고, 신뢰구간은 bootstrap 95%로 구한다.
- **주 지표**: 정확도 차이(F-M1P1 − F-M1P0). 가설은 결정표가 더 높다는 것이고, 기준은 p < .05이고 차이 > 0이다.
- **부 지표 (Holm 보정)**:
  - (a) T-M1P0 − F-M1P0 정확도
  - (b) d 반박 정답률, F-M1P1 − F-M1P0
  - (c) v 잘못 거부율, F-M1P0 − F-M1P1
- **기술 통계**: 3분류 표(수용 / 보류 / 거부), 판별 결정 분포
