# 시나리오 대사 리뷰

`scenarios/*.json` 을 사람이 읽는 형태로 변환한 문서다. `python3 scenarios/render_review.py` 로 다시 생성한다.

고칠 대사가 있으면 해당 JSON 을 수정한 뒤, 그 시나리오의 로그만 지우고 `python3 -m npc.cli runall --resume` 을 다시 돌리면 된다. 다른 조건·seed 의 기존 로그는 보존된다.

채점 대상이 아닌 턴(인사·단순 구매)은 회색 표기 없이 `—` 로 둔다.

## 승인

전체 18편 **승인 완료**. 대사를 고치려면 아래 `--revert` 로 되돌린 뒤 해당 JSON 을 수정한다.

```bash
python3 scenarios/approve.py            # 18편 전부 승인
python3 scenarios/approve.py S05_v1     # 일부만 승인
python3 scenarios/approve.py --list     # 현재 상태 확인
python3 scenarios/approve.py --revert   # 승인 취소
```

승인 상태는 표시용 메타데이터다. 프롬프트·`prompt_hash`·지표에 들어가지 않으므로 승인 후 재실행할 필요가 없다.
