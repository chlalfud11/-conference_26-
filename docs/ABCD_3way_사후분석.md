# ABCD 3분류 사후 분석 계획 (수용 / 보류 / 거부)

작성: 2026-10-20. 사용자 요청: "보류가 곧 거절로 처리되면 안 된다." 대화는 한 턴만 주고받는 것으로 두고, 그 뒤의 플레이어·SLM 행동은 후속 연구로 남긴다.
**이 분석은 사후 탐색 분석이다.** 각 실험의 사전등록 결과(v4 채택, fail-closed 중단, v5 미채택)는 바뀌지 않으며, 이 분석과 함께 보고한다. 이 문서는 숫자를 계산하기 전에 커밋한다.

## 분류
| 묶음 | 결정 |
|---|---|
| 수용 | accept_as_belief |
| 보류 | request_evidence, defer |
| 거부 | dispute, reject |

## 판별 판정
- **v (기록 있음)**: 수용이 정답이다. 보류는 비용(확인 질문 1회)이다. 거부는 오류(잘못 거부)다.
- **n (기록 없음)**: 수용은 오류(잘못 수용)다. 보류와 거부는 안전하다.
- **d (날짜 불일치)**: 반박이 정답이다. 보류는 안전하다. 수용은 오류(잘못 수용)다.

## 지표 (주장 턴)
1. **잘못 수용률**: n과 d 판에서 수용한 비율이다.
2. **잘못 거부율**: v 판에서 거부한 비율이다.
3. **보류율(v)**: v 판에서 보류한 비율이다. 진짜 손님이 치르는 확인 비용을 나타낸다.
4. **반박 정답률(d)**: 참고용으로 보고한다.

## 대상
- **v4 (84원천)**: F-M1P0, S-M1P0, F-M1P1, fail-closed, 재확인(RV)
  - fail-closed와 RV는 기록을 그대로 쓰지 않고 규칙을 적용해 유도한다. 유도 방식은 `abcd5_live.analyse`와 같다.
- **v5 검증 세트 (59원천)**: F-M1P1, fail-closed, RV

## 비교
- 각 세트 안에서 RV와 F-M1P1을 비교한다. 지표는 잘못 수용률과 잘못 거부율이다.
- 검정은 원천 단위 짝지은 sign-flip(20,000회)이다. 사후 분석이므로 p값은 참고용이다.
- 세트끼리는 데이터가 달라 직접 비교하지 않는다.
