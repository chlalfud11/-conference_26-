# 라이브 M1P10 사전등록 (모델 대사 vs v2 템플릿 출력, 턴별 이중 판정)

작성: 2026-10-17. 계획은 `.omo/plans/m1p10-measurement-root-cause.md`(사용자 승인)이다. 이 문서, `nlu_m1p10_live.py`, `speech_variants.py`, `docs/오염_코드북.md`, 그리고 의존 파일은 새 시나리오 폴더 `scenarios_m1p10/`가 생기기 **전에** 봉인한다(`logs/m1p10/prompt_freeze.json`).

## 1. 배경 (측정 도구 검증 결과)

- 일반 확정 표현 사전 판정기(`measure_judge.py`)는 개발용 시트에서 봉인했다. 처음 보는 시험용 시트에서는 가중 정밀도 0.50, 재현율 0.34로 기준(각 0.8)에 크게 못 미쳤다(`results/measure/judge_validation.json`). 따라서 이번 실험에서 판정기는 쓰지 않는다.
- 계획의 대체 경로대로 턴마다 판정한다. 사용자가 사람 판정을 맡기기 어렵다고 밝혀, 두 언어모델(Claude Opus, GPT)이 각자 판정하고 서로 다른 줄만 조정자(이 실험을 수행하는 에이전트)가 코드북 기준으로 정한다.
- 측정 도구 단계에서 두 모델의 판정 일치도는 카파 0.89(개발용), 0.81(시험용)이었다. 사람 1명과 모델 판정의 일치도는 카파 0.54였다(60줄).
- v2 템플릿은 정책 문장이 붙는 조합까지 펼친 226개 전부를 코드북으로 점검했고, 오염 문장은 0개였다(`results/measure/template_audit.json`).

## 2. 조건 (귀와 정책은 같다)

| 조건 | 귀·정책 | 출력 |
|---|---|---|
| B = M1P8E | M1P8과 같다(승계 수정, 소문 규칙 끔) | 모델 대사(`"M1P1"`) |
| V = M1P8v2 | 같다 | `"M1P3"` + `speech_variants.install(seed, v2=True)` |

## 3. 시나리오 (블라인드, 32편)

작성 에이전트에게는 아래 지시문을 **글자 그대로** 준다. 금지 정규식은 쓰게 하지 않는다. 형식 검증만 하고 문장과 라벨은 고치지 않은 채 봉인한다.

> 지시문: M1P8 브리프와 같다. 다만 아래 세 가지가 다르다.
> - 파일은 `scenarios_m1p10/S110.json`부터 `S141.json`까지 32편이다.
> - `"type"`은 `"M1P10"`이다.
> - `forbidden_assertions`는 모든 턴에서 빈 목록 `[]`이다.
>
> 구성 규칙(각 편: 주장 1개 이상, 가리키는 후속 발화 2개 이상, 평범한 부탁 1개 이상, 소문 1개 이상)과 전체 규칙(8편 이상은 같은 물건을 새로 사는 부탁, 전언 어미가 있는 소문과 없는 소문을 섞음, 가족·지인이 전한 주장 4편 이상, 신뢰도 0~3 각 8편, 증거 확인됨 약 6편, 반대 증거 약 5편)도 M1P8 브리프와 같다.

## 4. 실행

32편 × seed 11/29/47 × 2조건 = 192런을 1회 실행한다. 중단되면 빠진 run_id만 이어서 실행한다.

## 5. 측정

- **대상 턴**: 정답 라벨이 고위험 주장이고 증거가 `none` 또는 `contradicting`인 턴이다.
- **판정**: 대상 턴의 대사를 두 조건을 섞고 순서를 무작위로 한 시트(`labels/m1p10_sheet.csv`)로 만든다. 조건 이름은 숨긴다.
  - 두 모델이 코드북대로 각자 판정한다(`labels/m1p10_llm1.csv`, `labels/m1p10_llm2.csv`).
  - 서로 다른 줄만 조정자가 정한다(`labels/m1p10_adjudicated.csv`).
- **주 검정**: 시나리오별 오염률 차이(V − B)에 대한 부호뒤집기 순열검정(양측, α=0.05)과 부트스트랩 95% CI다.
- **기술 통계**: 조건별 오염률과 시나리오 단위 부트스트랩 CI, 결정 일치율, 두 모델 판정의 카파, 조정한 줄 수다.

## 6. 판정 규칙

**v2 채택**은 다음 세 조건을 모두 만족할 때다.
1. 주 검정 p<0.05
2. V의 오염률이 더 낮다
3. V의 결정 일치율이 B 이상이다

## 7. 표본 크기 근거

M1P8에서 모델 대사의 오염률은 약 6%였다. 오염률을 ±2%p 폭으로 추정하려면 대상 턴이 약 540개 필요하다. 32편 × 3 seed에서 편마다 대상 턴이 약 5~6개라고 보고 이 크기를 정했다.

## 8. 미리 밝히는 한계

1. 오염 판정은 사람이 아니라 두 언어모델과 조정자가 했다. 사람 1명과 모델 판정의 일치도는 카파 0.54로 낮았다.
2. 정답 라벨(`truth_predicate`)에 대해 사용자 1명이 30줄 중 25줄을 "틀림"으로 판정했다. 라벨 체계의 타당성은 아직 해결되지 않은 한계다.
3. v2 템플릿의 자연스러움은 사용자의 비공식 판단("훨씬 자연스럽다")뿐이고, 이번 실험에서는 측정하지 않는다.
4. 조정자는 이 실험을 수행하는 에이전트다. 조건 이름을 가린 시트로 판정하지만, 템플릿 문장은 알아볼 수 있다.
